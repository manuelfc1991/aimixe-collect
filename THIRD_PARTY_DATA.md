# Third-party data

The MIT licence in `LICENSE` covers the code. The language data bundled under
`collect/src/aimixe_collect/data/` is not covered by it and keeps its own terms:


  * reference.csv — derived from Glottolog 5.3 (CC-BY-4.0) and Unicode CLDR
    (Unicode-3.0); attribution in reference-SOURCES.md and reference-meta.json.
  * iso-639-3*.tab — ISO 639-3 code tables published by SIL International as
    the registration authority; see REGISTRIES.md for source URLs and terms.
  * iso15924.txt — ISO 15924 script codes, Unicode Consortium.
  * countries.tsv — ISO 3166-1 names from the Debian iso-codes package (LGPL-2.1).
